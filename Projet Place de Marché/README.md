# Classification d'articles e-commerce (NLP & Images)

## Contexte
Projet pour "Place du Marché" visant à automatiser la classification de produits à partir de leur description textuelle et de leurs images. L’objectif : améliorer l’expérience des vendeurs et des acheteurs en attribuant automatiquement la bonne catégorie produit.

## Objectifs
- Étudier la faisabilité d’un moteur de classification basé sur le texte et l’image.
- Extraire et comparer des features issues de **NLP** (BoW, Tf-Idf, Word2Vec, BERT, USE) et d’images (SIFT, CNN Transfer Learning).
- Implémenter un modèle de classification supervisée (VGG16 + data augmentation).
- Interroger l’API OpenFoodFacts et générer un fichier CSV exploitable.

## Outils & technologies
`pandas`, `numpy`, `matplotlib`, `seaborn`, `OpenCV`, `TensorFlow/Keras`, `scikit-learn`, `BERT`, `USE`, `API REST`.

## Compétences clés
- NLP (prétraitement, embeddings, clustering).
- Computer Vision (extraction de features, CNN).
- Réduction de dimension (PCA, t-SNE).
- API REST et automatisation des exports CSV.
